Changelog & Release Notes

What's new in Owl20 — releases, fixes, and milestones across both halves of the solution: the browser extension (DM UberDragon) and the Owlbear Rodeo extension (DM Sparks). Updates are delivered automatically through the extension stores and the Owlbear Rodeo extension system, so there's nothing for you to reinstall.

🏅 Owl20 Is Now an Official Verified Owlbear Rodeo Extension

July 3, 2026

The Owl20 OBR extension has been accepted onto the official Owlbear Rodeo extension store as a verified extension. For DMs this makes setup dramatically simpler: instead of hand-pasting a manifest URL, you click Copy Install Link on the store listing and Add Extension in your Owlbear Rodeo profile — done.

  • The DM Setup Guide has been rewritten around the new two-click install
  • Existing installs made via the old manifest URL keep working — no reinstall needed (details in the FAQ)

OBR Extension — Mimic Chat Roll Broadcasting

May 9, 2026 · Owlbear Rodeo extension

Rolls can now broadcast to Mimic Chat, so tables using DM Sparks' chat extension see D&D Beyond rolls inline in the chat stream alongside the Owl20 roll log.

v1.2.0 — Beyond20 Settings Sync, on Both Sides

March 22–24, 2026 · browser extension + Owlbear Rodeo extension

A coordinated release across both halves: the browser extension now relays Beyond20's settings events into the room, and the Owlbear Rodeo extension acts on them — so the in-room roll display follows each player's Beyond20 configuration instead of guessing at defaults.

  • Browser extension forwards Beyond20_Loaded and Beyond20_NewSettings events to the OBR extension
  • Settings replay on page load — join a room after configuring Beyond20 and your settings arrive with you
  • OBR extension surfaces configuration warnings and handles broken Beyond20 settings states instead of failing silently

Documentation Site Overhaul

March 21–22, 2026

This site got a top-to-bottom rework based on the questions we kept answering in Discord:

  • Dedicated step-by-step Player Setup and DM Setup guides
  • Expanded FAQ and a diagnostic Troubleshooting Guide
  • A How It Works deep dive into the architecture
  • Full mobile responsiveness fixes

OBR Extension — Winter Feature Wave

November 2025 – February 2026 · Owlbear Rodeo extension

A steady run of quality-of-life releases on the Owlbear Rodeo side, shaped by feedback from our weekly sessions:

  • Initiative tracker integration — initiative rolls are added to Owlbear Rodeo's official tracker automatically when the token text matches the character name
  • Whisper roll support — private rolls stay between the roller and the DM
  • Character sheet link-back — click a roll in the log to jump to the D&D Beyond sheet it came from
  • HP broadcast and player-color bubbles with tooltips in the roll log
  • Light/dark theme — the roll log follows Owlbear Rodeo's style and switches with it
  • Handling for rolls without a defined character, DOMPurify hardening, and listing prep for the Owlbear Rodeo extension store

v1.1.3 — Scene-Change Stability Fix

November 15, 2025 · browser extension

Fixed an iframe postMessage null error that could stop rolls from appearing after an Owlbear Rodeo scene change replaced the extension's iframe. If your table saw rolls mysteriously stop mid-session, this was the fix.

Documentation Site Launched

November 13, 2025

owl20.uberdragon.org went live as the home for Owl20 setup guides, troubleshooting, and project news.

v1.1.1 — First Public Release

October 24–27, 2025 · browser extension + Owlbear Rodeo extension

Owl20 went public as a pair: DM Sparks stood up the first working Owlbear Rodeo extension, and days later the browser extension launched on the Chrome Web Store, Edge Add-ons, and Firefox Add-ons after weeks of play-testing in our own campaigns.
